# 功能擴充驗收紀錄

**驗收日期：** 2026-09-11

## 關鍵字搜尋

首頁已加入「搜尋篇名、詩句、譯文或註詞」入口。以「伊人」測試時，系統顯示〈蒹葭〉、〈伐木〉、〈白駒〉三筆結果，並在目錄中呈現命中上下文；從首頁送出後會自動開啟第一筆命中的〈蒹葭〉。`?q=` 搜尋網址亦會採用同一邏輯。

## 本機收藏

每篇標題下方已有明確的「加入收藏」按鈕。測試〈關雎〉後，按鈕切換為「已加入收藏／已儲存於此瀏覽器」，左側收藏數由 0 更新為 1。收藏資料保存在 `localStorage` 的 `shijing-reader:stars:v1`，不會上傳伺服器。

## 白話譯註

每篇都有「白話譯註」頁籤，包含逐章白話、3–6項詞語註釋及閱讀提示。全部305篇先由 `gpt-5-mini` 生成初稿，再由 `gpt-5` 進行編輯覆核及現代白話改寫；介面明示尚待人類學者逐篇核定。自動驗證確認篇次完整、章數一致、註詞逐字存在於原文，且沒有任何譯文章節與原文相同或高度相似。

## 主題視覺

愛情、農事、征役、祭祀、宴飲、思歸六類在閱讀器中使用不同的低飽和水墨色背景與標籤色；305張社群分享圖亦採相同主題配色與「情／耕／役／祭／宴／歸」背景題字。

## 版本資料

`dateModified` 與短版 Git SHA 由建置流程讀取部署提交，不再人工填日期。Open Graph 圖片網址帶 Git SHA 查詢參數，後續每次部署都會自然產生新的快取鍵。

## 響應式視覺

已以 1440 × 900 桌面視窗及 390 × 844 手機視窗抽查首頁和〈蒹葭〉閱讀頁。桌面版搜尋框、雙欄目錄、主題標籤與收藏控制均無溢出；手機首頁搜尋及主要操作保持完整，閱讀頁的標題、收藏按鈕、四個內容頁籤與正文均可辨識且沒有水平裁切。
